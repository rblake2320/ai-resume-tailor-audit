## Laya fit and measured result

Added an optional **local advisory CLI** for categorizing short public English
job requirements. It uses the exact `convaiinnovations/laya` root checkpoint,
cached weights, CPU by default, a conservative token budget, and atomic reports.
It receives structured excerpts, not screenshots or candidate resumes.

**Worked:** actual inference and report generation, 10/12 correct on the retained
synthetic balanced fixture. **Failed:** salary and travel classification. Those
two misses remain in `laya-benchmark.json`; runtime temperature warning is
retained in `laya-runtime.txt`, probabilities are marked uncalibrated.
Consequently the tool stays advisory and never controls evidence validity,
match scores, disclosure, approval, or application submission.

## Reproduce

Use Node 24.17.x (CI pins 24.17.0):

```powershell
npm ci
npm run verify
# Requires Python Playwright and its Chromium installation:
npm run test:browser
```

The browser test starts the production `next start` entrypoint on a fresh
loopback port, performs the Windows private-storage preflight, then terminates
its owned process. It uses synthetic NDJSON interception for generation. The
real local private-URL refusal and capabilities requests reach the shipped
server. Screenshots, control inventory and outcomes are retained in the dated
evidence directory; reruns write under `.resume-foundry/`.
