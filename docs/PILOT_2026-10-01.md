# Real tester pilot — October 1, 2026

Share https://resume-foundry-private-pilot.rblake2320.workers.dev and send each
tester a different invite code separately. The ten codes and separate owner
secret are in the ignored, owner-restricted
`.resume-foundry/pilot/operator/owner-secrets.json` in the deployed checkout.
Never paste that bundle into an issue, PR, public URL or shared document.

Owner dashboard: https://resume-foundry-private-pilot.rblake2320.workers.dev/pilot/admin.
Use `ADMIN_SECRET`, not a tester code. The dashboard shows retained coverage,
completion/error counts, usage steps, ratings and reviewed comments, with bounded
JSON downloads and next-page navigation. Résumé/job text is not included in the
telemetry schema. Testers may choose no tracking or withdraw and delete their
shared data. Authentication and budget counters remain operational necessities.

This is a functioning invite-only pilot with real generation, not a sample-only
demo. The existing local Ollama service executes `qwen3-vl:8b-instruct`; fixed
loopback transport, schema/source-citation checks, incomplete-turn rejection and
one concurrent inference apply. Paid providers are independently disabled at
both gateway and native route; no fallback or automatic generation retry occurs.
Combined résumé/job input is capped at 12,000 characters. Review every generated
document: scores are model estimates and evidence checks do not replace human
fact-checking.

Three attempts per invite and ten globally are admitted atomically per UTC day.
Failed/cancelled requests can consume an attempt. Initial receiving checks used
four global attempts on October 1 (three completed and one origin interruption); those counters were deliberately preserved.
The UTC reset occurs at 7 p.m. Chicago daylight time on this date. Optional usage
is limited to 500 events and feedback to 20 submissions per tester/day; shared
events/comments expire after 30 days. These are pilot limits, not a production
capacity promise.

The Cloudflare Worker and dedicated D1 store are hosted independently of the PC.
The native application and model still run on this PC. Keep it awake with internet
connectivity during tester sessions; no power settings or automatic startup hooks
were changed. The dedicated origin requires its private header even on static
assets. Agent operations, Google connections and employer submission writes are
unavailable through this pilot. Those features remain part of the private workshop.

After a reboot or tunnel loss, ensure the existing local model service is running
and run `npm run pilot:share` from the deployed checkout. If no build exists, first
run `npm ci`, `npm ci --prefix pilot`, then `npm run verify`. The recovery command
reuses healthy dedicated processes, rejects a conflicting port, and updates the
stable share link to the new protected tunnel without rotating invite codes.
Inspect ignored origin/tunnel logs on failure. No model-server launch, weight
download, paid subscription or account-wide DNS change is performed by recovery.

Cloudflare documents Quick Tunnels as temporary testing infrastructure with no
uptime guarantee and changing origin hostnames. The stable Worker URL and recovery
command address hostname changes, but do not provide always-on hosting.
[Cloudflare Quick Tunnel documentation](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

passed 615 tests, lint, typecheck, production build and a zero-finding dependency

private production browser suite passed 17 checks. Provider and hosted receipts
remain distinct from synthetic browser tests.
